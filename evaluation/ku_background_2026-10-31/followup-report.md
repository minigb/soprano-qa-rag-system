## 실제로 바뀐 답변과 코드

- 영어 조옮김 질문: 부정형 질문의 정답과 요청 허용 여부가 혼동되던 입력 판정을 음악 질문/주입 공격/비음악 요청의 범주로 바꿨다. 출처가 없는 음높이 개념 설명에는 짧은 질문·언어 입력과 제한된 추론을 사용한다. 입력·출력 검토는 전체 문맥을 유지한다.
- 영어 일반 레가토 연습: 일반 성악 연습을 선택한 곡의 KU로만 해결하려던 라우팅을 고쳤다. 편한 음역·짧은 구절·필요한 호흡을 안내하며 개인의 호흡량을 단정하지 않는다.
- 로지나의 성격: 검색의 성격 표현 조건에 ‘당차다·활발하다·확신에 차다·쾌활하다’ 같은 어휘를 포함해, 선택 구간14–15를 설명하는 실제 KU를 찾는다. 원문의 해석상 유보와 권고를 유지한다.
- p/PP: 두 한국어 자료에 명시된 시작 반주 표기와 조용한 성악 첫소리 권고를 각각 확인하는 작은 출처 비교 함수를 사용한다. 모호한 주장·부정·가정·다른 위치·같은 표기·설명된 원인 등은 기존 원문 보존 경로로 돌아간다. 값과 인용은 실제 출처에서 얻으며 질문 ID·전문가 정답을 조회하지 않는다.

p/PP의 현재 답변:

> 첫 번째 자료는 시작 반주의 셈여림을 PP로, 두 번째 자료는 p로 설명합니다.
> 두 설명이 다른 이유는 이 자료만으로 확정할 수 없습니다.
> 두 자료 모두 노래의 첫소리를 너무 크게 시작하지 않는 방향을 권합니다.

반주의 표기를 성악가에게 적용할 의무로 바꾸지 않았고, 한 자료에만 있는 호흡 지지·울림을 공통 조언으로 묶지 않았다. 판본 차이·작곡가 의도·오류를 원인으로 만들어 내지 않았다. 영어는 출처별 문장에 인용을 따로 붙이며 별도23건 진단에서도 올바르게 응답했다.

이 비교는 일반적인 출처 모순 해결기가 아니다. 코드가 지원하는 제한된 명시적 패턴에 적용하며 모든 입력·출력·인용·범위 검토를 거친다. API에는 `llm_guarded_source_comparison`으로 기록하고 Lab 화면에는 `Source comparison`으로 표시한다. 고정 출처 평가 wrapper는 기존 계약상 이 모드를 `llm`으로 표기하지만 실제 생성 방식은 위와 같다.

## 의미 검토와 남은 제한

E25 대비 전체 packet281/290, 정상 packet211/220이 동일하다. 바뀐 정상9개를 직접 대조했다. 이전에 의미를 점검한41개는39개가 전체 packet까지 같고, 변경된2개 p/PP를 다시 읽었다. Claude 판정은41개 중40개 faithful,1개 minor_drift이며 중대한 변경은0개다. 원문 인용165/165, 영어 번역38/38은 저장된 실제 출처/번역과 일치했다. 이 일치는 원자료의 사실성이나 완전한 관련성을 보증하지 않는다.

남은 사항도 기록했다. 영어 조옮김 답변에는 옥타브 이동을 조성 변경의 예처럼 표현한 작은 오류가 있다. 일반 레가토 연습은 구체적인 음형 제시가 부족해 전체 평가에서2점을 받았다. 한국어 느린 가사 연습은 리듬·속도 진행을 더 구체적으로 안내할 여지가 있고, 기존 마이크 설명의 원문 모호성·반복도 남아 있다. 핵심 오거절과 출처 의미 문제를 해결했지만 모든 문장이 완벽하다고 주장하지 않는다.

조옮김·옥타브·이명동음 구분은 직접 검토할 때 [Steps to Music Theory의 음정/이조 설명](https://odp.library.tamu.edu/stepstomusictheory/chapter/more-intervals/)과 [Open Music Theory의 음고·옥타브 설명](https://openmusictheory.github.io/pitches.html)을 참고했다. E35/E36에서 정의 안내를 길게 넣는 실험은 오히려 개념 혼동을 남겨 제거했다. 해당 실패도 보존했다. Claude가 p/PP 원인으로 다른 판본을 제안한 평가는 근거가 없어 답변 목표로 채택하지 않았다.

## 평가 조건과 재현

BERTScore에는 전문가가 주석한 한국어105문항만 사용했다(개발43·검증62). 원질문 그룹은 분리되지만 KU6개가 겹치고, 실패를 수정에 사용한 재사용 내부 평가다. 새 독립 holdout 성능으로 해석하지 않는다. 설정은 `xlm-roberta-large`,18층,IDF=false,raw/unrescaled F1,slow tokenizer로 고정했다. 검증62/62가 응답했고 잘린 텍스트는0개다. 답변 전체를 평가하며 실패/거절은0점으로 포함한다. 원문·정답·분모·설정을 유리하게 바꾸지 않았다.

원본 시스템과 E25의 기존 측정 파일·BERTScore는 바이트 단위로 재사용했다. E37은 새 warmup 뒤 전체290개를 새로 실행했다. Qwen3-14B Q6_K, A6000, 동일 검색 모델·corpus·기본 LLM 설정을 사용했다. 일반 음높이 개념의 추론 단계는1536토큰 한도이며 나머지 생성 경로와 구분해 기록했다. Claude Opus5.5 CLI는 시스템명과 BERTScore를 가린541개 고유 packet을 평가했다. 동일 모델/루브릭/runner/전체 packet 조건을 만족한503개 기존 최초 유효 판정을 재사용하고38개를 새로 평가했다. 좋지 않은 점수를 이유로 재판정하지 않았다.

간접 공격은 깨끗한 검색 뒤 악성 자료를 강제 노출하는 시험으로, 검색 색인 오염 전체를 검증하지는 않는다. 기존 위협 모델과 관련 논문은 [보안 연구 검토](../../docs/rag-security-research.md)에 정리돼 있다.

Root RAG648개, Lab RAG648개, Lab demo44개 테스트가 통과했다. 양쪽21개 production 모듈과 LLM 설정이 평가 snapshot과 일치한다. 사용량 리셋 중지 조건과 Discord/notifier는 사용하지 않았다.
