## 설정과 평가의 범위

BERTScore는 전문가 한국어105개를 원질문 단위로 dev43/validation62로 나눴다.
원질문그룹은 겹치지 않지만 KU6개는 공유한다. 이후 관측된 실패를 수정에
사용했으므로 **재사용 내부 평가**이며 독립적인 새 test set은 아니다.
모든 한국어/영어 정상·공격 결과를 같은 전문가 BERTScore로 평가했다는 뜻도 아니다.

고정 설정은 [config/bertscore.json](../../config/bertscore.json):
`xlm-roberta-large`, layer18, IDFfalse, raw/unrescaled, slow tokenizer, langko,
revision `c23d21b0620b635a76227c604d44e43a9f0ee389`다. 개발 단계18설정 중
선택한 뒤 바꾸지 않았다. 전체 표시 답변과 고정된 모든 해당 KU를 평가했고,
validation62개에서 잘린 텍스트는0개였다. 인용은 원문 중복도를 높인다.
역사적 중대 오류4개 중3개도0.90을 넘었으므로 **0.97346은97%정확도가 아니다**.

Qwen3-14B Q6_K, temperature0/top_p0.8/max_tokens768/n_ctx8192;
Qwen3-Embedding-0.6B Q8_0를 사용했다. 영어는 원문 SHA가 맞는129개 검토 번역을
재사용하고 새/변경 원문은 별도1536-token 번역을 한다. 이 번역들은 기계 작성·
Codex 검토·별도 Claude 판정이며 인간 전문가 영어 정답이 아니다. 준비 비용은
요청 지연에 포함되지 않는다. 비교 대상은 추가 번역 자원·계산 기능을 포함한
전체 시스템이며, 보안 프롬프트만 바꾼 통제 실험은 아니다.

평가자는 사용자 지정 Claude Opus5.5 CLI(`claude-opus-5-5`)다.
916개 unique packet 중 E19와 동일한887개는 최초 판정과 계약을 그대로
재사용하고29개는 새로 평가했다. 불리한 점수를 이유로 재시도하지 않았다.
같은 답변에 대해 E24는 p/PP2를 minor, E25는 faithful로 판정했다.
직접 검토의 한계 지적은 유지하며, E24의94.74→E25의94.82 차이는 정상
답변 개선 효과가 아닌 평가자 변동이다. 생성 모델의 output guard와 평가자는 별개다.

간접공격은 clean retrieval 후 근거에 강제로 주입했다. 공격 문서의 검색 진입
성공률이나 새로운 적응형 공격에 대한 보장을 측정하지 않았다.
