# Gemini 3.8 Flash와 로컬 Qwen3-14B 비교

2026-11-07. 작업 브랜치: `codex/helpful-rag-responses`.

같은 질문·검색 결과·생성 프롬프트에서 Gemini가 반환한 답변의 의미 보존과
자연스러움은 개선됐다. 다만 API 실패와 긴 지연이 발생했다. **전문가105문항에서
실패를 포함한 BERTScore는0.897379로0.9 목표에 미달했다.** 반환된99개 답변만의
점수0.951765와 구분해야 한다. 기본 설정은 유지하고 Gemini 연결을 선택 설정으로 제공한다.

## 전문가 기반 답변 품질

로컬 비교 기준은 의미 보존 프롬프트 후보J의 Qwen3-14B-Q6_K다. 전문가 주석 기반
105문항과 이전 거절 사례의 변형4개를 사용했다. Gemini는109개 중103개에 답변했고,
원래105문항에서는99개에 답변했다. 아래 표는 양쪽 답변이 모두 있는 **동일99문항**이다.

| 지표 | 로컬14B J | Gemini3.8Flash |
|---|---:|---:|
| 중대한 의미 변경 | 4/99 | 0/99 |
| 경미한 의미 변경 | 35/99 | 6/99 |
| 충분한 답변 | 88/99 | 97/99 |
| 자연스러움, 4점 만점 | 3.495 | 3.778 |
| 음악 질문 오거절 | 0/99 | 0/99 |
| 동일99문항 BERTScore F1 | 0.940459 | 0.951765 |

자연스러움은33건 상승,59건 동일,7건 하락했다. API 실패6건은 의미·자연스러움을
판정할 답변이 없다. 로컬 전체105문항은 중대한 의미 변경4건, 자연스러움3.486,
BERTScore0.939943이다. Gemini 전체105문항의 보수적 BERTScore는 실패6건에0점을
반영한0.897379이다. 답변 잘림과 인코더 길이 초과는 모두0건이다.

기존 거절5문항은 두 모델 모두 답변했고 Claude의 의미 보존 판정도5/5였다.
그러나 이5건의 자연스러움은 **3.6→3.2/4로 하락**했다. 모든 문항에서 개선된 것은 아니다.

## 직접 확인한 의미 차이

| 사례 | 로컬J의 문제 | Gemini 답변에서 확인한 변화 |
|---|---|---|
| ‘꽃바람’ 발음 | 받침을 살리기 위한 보완 발음이 빠짐 | `꼬-ㅊ-빠-람`과 자음 사이 짧은 멈춤을 복원 |
| linguaggio의 gg | 두 번 발음되는 ‘느낌’이 실제 두 번 발음하라는 지시로 확대 | ‘두 번 발음되는 느낌’을 유지 |
| 곡이 너무 높을 때 | 조옮김 허용이 일반적인 편곡 허용으로 확대 | 조성 변경으로 범위를 제한하고 구체적 예외를 유지 |
| 기교 구간의 가사 | 단어를 마무리할 조건이 ‘아-’ 선택지까지 확대 | ‘단어의 모음으로 이어 부를 경우’라는 조건을 명시 |
| p와PP | 서로 다른 표기의 원인을 추측 | 두 자료의 p/PP 설명을 구분하고 원인은 확정하지 않음 |

다른 답변에도 가능성의 단정, 특정 마디의 효과를 전체 곡으로 확대하는 표현,
작곡가 이름 표기 오류가 남았다. 이 결과가 일반적인 무오류를 뜻하지는 않는다.

## 한국어·영어 공격과 정상 질문

74개 목록 중 기존 로컬 영어 검색어 번역이 실패한1개는 생성 입력 자체가 없어
동일 입력 비교에서 제외했다. 나머지73개 중 Gemini API 실패1개가 있어72개 답변을 판정했다.

| 유형 | 로컬J | Gemini | 기준 |
|---|---:|---:|---|
| 직접 공격 성공 | 9/29 | 0/29 | 양쪽 답변이 있는 동일29개; 추가1개 Gemini API 오류 |
| 직접 공격 성공, 한국어 | 5/15 | 0/15 | 동일15개 |
| 직접 공격 성공, 영어 | 4/14 | 0/14 | 동일14개 |
| KU 주입 공격 성공 | 0/20 | 0/20 | 기존 자료 차단을 포함한 시스템 결과 |
| 정상 음악 질문 오거절 | 0/12 | 0/12 | 한국어6개·영어6개 |
| 범위 밖 과제 수행 | 1/11 | 0/11 | 기존 번역 실패1개 별도 제외 |

KU 주입20개 중9개는 기존 `unsafe_source_excluded` 경로로 자료가 제외됐다.
생성 입력의 근거가 빈 사례는 총10개다. 따라서20개 전체를 생성 모델만의 방어로
해석하면 안 된다. API 오류도 방어 성공으로 세지 않았다.

Gemini의 범위 밖11개 답변은 성악·음악 도우미라는 역할을 설명하고 음악 질문으로
안내했다. 정상 음악 질문의 오거절과 구분했다. 예를 들어 요리 질문에는 성악 도우미의
범위를 설명하고 《송어》의 가창·반주·호흡·발음 질문을 안내했다.
정상 음악12개 답변의 자연스러움은3.583→3.833/4였다.

## 응답 시간과 API 실패

이전과 같은 일반 음악10문항을 별도로 순차 실행했다. 로컬은 문항당2회,
Gemini는1회 관측이다. 아래 시간은 **생성 단계**이며 검색·영어 번역·평가자의 시간과
평가 요청 사이의10초 간격은 포함하지 않는다. Gemini는 첫 연결 설정 시간을 포함한다.

| 지표 | 로컬14B | Gemini API |
|---|---:|---:|
| 평균 | 2.690초 | 20.448초 |
| 중앙값 | 2.381초 | 11.003초 |

별도 시간 측정10개는 모두 답변됐다. 이 추가 답변들은 품질 평가나 BERTScore에
대입하지 않았다. 전문가 품질 평가 중에는58개 출력 토큰의 답변에도151초가 걸리는 등
짧은 답변의 API 대기가 길어진 사례가 있었다. 성공한 전문가 호출의 최대 시간은157초였다.

같은 Vertex 프로젝트의 YouTube 대량 작업을 유지한 상태다. 측정 시점과 서비스 부하가
다르므로 이 차이를 모델 고유 속도나 모델 크기의 효과로 단정할 수 없다. 품질 생성 중
동시성과 요청 간격을 변경한 기록도 보존했고, 별도의 순차 시간 측정을 구분했다.

품질 평가의182회 호출 결과는 답변175개·기술 오류7개다. 오류는429 네 건,
504 두 건,4번 프로젝트 설정 오류403 한 건이다. 전문가105개에 포함된 실패는6건이다.
**403은 모델의 답변 품질 문제가 아니라 실험 연결 설정 실패**이며, 전체 기록에서
제외하거나 성공 답변으로 바꾸지 않았다. 사용자가4번 사용을 철회한 이후에는3번만 사용했다.
현재 어댑터는 자동 API 재시도나 다른 모델로의 대체를 하지 않는다.

## 구현과 재현

선택 설정은 [`config/settings.gemini.json`](../../config/settings.gemini.json)이다.
hybrid BM25+embedding 검색, J 프롬프트, 영어 검색어 번역용14B를 유지한다.
한국어는 로컬 답변 모델을 호출하지 않는다. 입력 판정·KU 재선택·출력 검사를 위한
LLM 호출이나 원문 대입은 추가하지 않았다. Claude 평가는 서비스 밖에서 수행했다.

Gemini3.8Flash LOW/출력2048토큰과 Qwen3-14B 비사고/출력768토큰의 비교다.
질문·KU 순서·마디 범위·악보 문맥·system/user 문자열을 고정했다. 토크나이저,
학습 방식, 추론 방식, API 역할 처리는 서로 다르다. Flash가 샘플링 필드를 무시한다는
[공식 안내](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-3-8-flash)도
고려해야 하므로, 모델 크기만의 인과 실험으로 해석하지 않는다.

평가자는 기존 rubric의 Claude Opus5.5 CLI이며 첫 유효 판정을 사용했다.
BERTScore는 기존 XLM-R-large/layer18/noIDF/raw F1, revision
`c23d21b0620b635a76227c604d44e43a9f0ee389`를 유지했다. 지표 설정 탐색·답변 잘림·
점수 개선용 재생성은 없다. 기존 개발 문항의 재사용이며 새로운 holdout이나 전체460개
평가는 아니다. 중단된 이전 API 모델 실험은 별도 부분 기록으로 남겼고 이 통계에 섞지 않았다.

연결 구현은693개 테스트를 통과했고, Flash 설정 변경 후 관련19개 테스트도 통과했다.
의존성 검사도 통과했다. 실제 서비스 호출 결과는 `service-smoke*.json`,
보존·입력·모델·완료 수 검증은 `verification.json`에서 확인할 수 있다.
실제 한국어 호출은 로컬 생성0회로5.553초, 영어 호출은 로컬 검색어 번역1회와
Gemini 생성으로8.843초였다. 초기 로딩을 포함한 단일 연결 확인이며 위10문항 시간 측정과 구분한다.
원본/main·로컬 설정·corpus·기존460개 데모는 보존했다.
